# Domio

Веб-приложение для взаимодействия жильцов многоквартирных домов
с управляющей компанией (УК). Дипломный проект.

## Возможности

- Жители создают заявки и отслеживают их статус
- Сотрудники УК обрабатывают заявки и публикуют объявления
- Администратор управляет пользователями и ролями

## Технологии

- Backend: Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic, pytest
- Frontend: React, TypeScript, Vite
- Docker (на финальном этапе)

## Структура репозитория

- `backend/`: серверная часть (появится в задаче BE-02)
- `frontend/`: клиентская часть (появится в задаче FE-01)
- `docs/`: документация и контракт API (`docs/api.md`)

## Правила работы с Git

- Ветки: `main` (релизы), `develop` (интеграция), `feature/<ID>-<slug>`
- Одна задача = одна ветка = один Pull Request
- В `main` и `develop` напрямую не пушим
- PR должен посмотреть минимум один другой участник
